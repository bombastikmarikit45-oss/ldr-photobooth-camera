How to use: Open this same GitHub Pages link on both phones. Enter the Apps Script photobooth room code and PIN. Creator chooses A and partner chooses B. Enable both cameras. See your poses side-by-side and press Capture together. Your 4 paired moments appear in the strip.

Saving to Google Drive: Launch this camera site using Start live preview inside the Apps Script booth to send your own captured picture back for review and saving there. If opened directly, download the completed strip here.

Camera video is transmitted via WebRTC and is not recorded on a server by this page. The free third-party PeerJS signaling service helps connect your devices. TURN relay is not configured, so some mobile or corporate networks cannot connect. Use this for casual photos, not sensitive/private video.
